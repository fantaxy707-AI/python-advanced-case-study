Ringkasan Proyek

Repository ini berisi penyelesaian 3 studi kasus yang maenggunakan fitur lanjutan Python dalam skenario nyata.



Case 1: Analisis Nilai Mahasiswa

Sistem pemrosesan data nilai mahasiswa yang memanfaatkan List Comprehension, Lambda Function, dan Filtering Sorting bawaan Python. Tujuannya untuk mengkalkulasi nilai akhir dan melakukan pemeringkatan secara efisien tanpa menggunakan perulangan for bertingkat.



Case 2: Simulasi Sensor IoT Hemat Memori

Sistem pembacaan data suhu berbasis streaming menggunakan Generator Function dan yield. Pendekatan ini memastikan efisiensi memori karena data diekstraksi satu per satu tanpa memuat seluruh titik data ke dalam RAM secara bersamaan.



Case 3: Keamanan Akun dan Audit Log Login

Sistem otentikasi yang menggabungkan validasi pola string menggunakan RegEx, enkapsulasi data melalui Object-Oriented Programming, serta implementasi Decorator untuk mencatat riwayat login secara otomatis tanpa mengganggu fungsi utama.
