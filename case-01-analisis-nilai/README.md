\# Studi Kasus 1: Analisis Nilai Mahasiswa



**Masalah yang Diselesaikan:**

Mengoptimasi proses perhitungan nilai akhir, pemfilteran mahasiswa berprestasi (nilai > 80), dan pemeringkatan mahasiswa tanpa menggunakan perulangan 'for' manual bertingkat.



**Konsep Python yang Digunakan:**

1\.  **List Comprehension:** Untuk kalkulasi dan pemfilteran nilai secara efisien dalam satu baris kode.

2\.  **Lambda Function:** Sebagai kunci kustom (parameter 'key') pada fungsi 'sorted()' untuk mengurutkan mahasiswa berdasarkan perhitungan nilai akhir tanpa mendeklarasikan fungsi 'def' terpisah.



**Cara Menjalankan Script:**

Pastikan Anda berada di direktori 'case-01-analisis-nilai', lalu jalankan perintah berikut di terminal:

'python main.py'
